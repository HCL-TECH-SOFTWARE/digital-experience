# Using the Search Admin UI

This section describes how to use the Search Admin UI to manage DX Search V2 components.

## Prerequisites

Before you can use the Search Admin UI, ensure you:

- Have at least an **Administrator** role. For more information, refer to [Accessing the Search Admin UI](../access.md).
- Have enabled the Search Admin UI. For more information, refer to [Enabling and disabling the Search Admin UI](../enable.md).

Once available, the Search Admin UI displays the following management areas:

- **[Managing content sources](content_sources.md)**  
Create, update, delete, and view the content sources used by Search V2.
- **[Managing crawlers](crawlers.md)**  
Create, update, delete, trigger, and monitor crawlers for content sources that support crawling.
- **[Managing common field mappings](common_field_mappings.md)**  
Map common search result fields to the corresponding fields for each content source type.
- **[Managing NLS translations](nls_translations.md)**  
Manage translations of common field names to support different languages.
