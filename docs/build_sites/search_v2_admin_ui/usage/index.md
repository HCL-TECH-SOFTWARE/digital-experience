# Using the Search Admin UI

This section describes how to use the Search Admin UI to manage DX Search V2 components.

!!! note
    You must have at least Administrator access to use the Search Admin UI. For more information, refer to [Accessing the Search Admin UI](../access.md).

Once accessed, the Search Admin UI displays the following management areas:

- **[Content Sources](content_sources.md)**  
Create, update, delete, and view the content sources used by Search V2.
- **[Crawlers](crawlers.md)**  
Create, update, delete, trigger, and monitor crawlers for content sources that support crawling.
- **[Common Field Mappings](common_field_mappings.md)**  
Map common search result fields to the corresponding fields for each content source type.
- **[NLS Translations](nls_translations.md)**  
Manage translations of common field names to support different languages.
