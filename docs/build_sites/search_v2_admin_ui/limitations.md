# Limitations of the Search Admin UI

Refer to the following limitations when using the Search Admin UI:

- Access is restricted to administrator users only.
- Crawler functionality is only available for JCR, Portal, WCM, and Website content source types. DAM and People content sources do not support crawlers; they use the Content Push API to index data instead.
- Default common field mappings cannot be renamed or deleted.
- A crawler that is currently running cannot be updated or deleted.
