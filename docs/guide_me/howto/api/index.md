# API

This section includes how-to articles about API-related content in HCL Digital Experience (DX).  

- **[How to create a JSP to update WCM library roles using WCM API](./updateWcmLibraryRoles.md)**  
Learn how to create and execute a JSP file using the WCM API to update library access permissions and user roles in HCL DX.
- **[How to create a JSP using the WCM `QueryService` API](./createJSPUsingWCMAPI.md)**  
Learn how to create a JSP that uses the WCM `QueryService` API to select content based on an authoring template and a specific range of last modified dates.
- **[How to limit the number of items returned by an iterator when using the WCM API](./LimitIteratorWCMAPI.md)**  
Learn how to configure the `iterator.pagesize` custom property in HCL DX to control the maximum number of items returned by an iterator when using the WCM API.
- **[How to use WCM API `findByName` method to retrieve top-level site areas](./findTopLevelSiteArea.md)**  
Learn how to retrieve top-level site areas using the WCM API `findByName` method and `DocumentTypes.Site` parameter.
- **[How to use WCM API to generate a URL based on the locale of the request](./generateURLWCMAPI.md)**  
Learn how to generate a URL based on the request locale using WCM APIs to inspect locales and deliver targeted content components.  
- **[How to use WCM API to search for pages in the Portal site library](./searchPagesInPortalSiteLibrary.md)**  
Learn how to use a JSP script with the WCM API to search for pages in the Portal site library by title and display their page names and path locations.
