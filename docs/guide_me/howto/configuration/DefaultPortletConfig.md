# How to change the default portlet configuration

## Applies to

> HCL Digital Experience v9.5 and higher

## Introduction

Default configuration changes apply to every instance of a portlet across all deployed pages. This article describes how to change the default settings of a portlet on all pages where it is deployed.

???+ info "Important"
    If the change is made to a portlet located in the base portal, it will take effect on the deployments of the portlet in all virtual portals as well. If the change is made to a portlet in a virtual portal, it will take effect on the deployments of the portlet in all virtual portals as well as the base portal.

## Instructions

To change the default settings of a Portlet, do the following:

1. Log in to HCL DX as an administrator.
2. Navigate to the page where the portlet is deployed.
3. Turn on **Edit Mode**.
4. Locate the portlet you want to modify on the page.
5. Select the menu icon in the upper-right corner of the portlet.
6. Select **Configure**.
7. Locate the setting that you want to modify and make the required change.
8. Select **Apply** to save your changes.
