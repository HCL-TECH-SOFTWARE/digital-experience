# How to hide the impersonation button for a normal user, but keep for administrators

## Applies to

> HCL Digital Experience v8.5 and higher

## Introduction

We would like to hide the impersonation button for a normal user, but leave it enabled for administrators.

## Instructions

Please carry out the following steps:

1. Go to Portal Administration -> Pages -> Content Root -> Hidden Pages

2. Click on the permissions icon for the Impersonation page -> edit user role -> revoke all authentication users.  

3. Restart the portal server and check.
