# Plan your deployment

Deciding on a deployment approach for your HCL Digital Experience (DX) depends on several factors, including your environment's scale, security requirements, and available resources. Consider the following deployment scenarios to determine the best approach for your organization.

- **[Kubernetes deployment](./container_deployment/index.md)**  
Learn how to deploy and manage HCL DX 9.5 deployments on container platforms using Helm.
- **[Traditional deployment](./traditional_deployment/index.md)**  
Learn how to install and maintain HCL DX 9.5 on virtual machines or physical servers using traditional methods.
- **[Hybrid deployment](../../deployment/install/hybrid/index.md)**  
Learn how to deploy and manage HCL DX 9.5 core Portal Server and Web Content Manager services on-premises, and connect to cloud native components using Helm in a production environment.
- **[Development deployment](./docker/index.md)**  
Learn how to build and run HCL DX 9.5 as standalone containers using Docker and Docker Compose.
