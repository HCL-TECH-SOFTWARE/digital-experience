# Getting started with HCL Digital Experience

In this Getting Started with HCL Digital Experience section, you get an introduction to HCL Digital Experience. This provides an [HCL Digital Experience overview](./product_overview/index.md) where you learn the market trends, what, why, and how HCL Digital Experience is the right solution. You can also see DX in Action with a few recorded demos and learn how to run these demos yourself using a sandbox for HCL Digital Experience Solution Modules Business Solution that runs on HCL SoFy (HCL Solutions Factory). For more information, see [DX Introduction course](https://hclsw.co/hdx-intro). For specific lessons, access the following links:

- [HCL Digital Experience Overview](https://hclsoftwareu.hcl-software.com/component/axs/?view=sso_config&id=4&forward=https%3A%2F%2Fhclsoftwareu.hcl-software.com%2Fcourses%2Flesson%2F%3Fid%3D273): In this lesson, you get an overview on the HCL DX and find many useful links.

- [HCL Digital Experience in Action](https://hclsoftwareu.hcl-software.com/component/axs/?view=sso_config&id=4&forward=https%3A%2F%2Fhclsoftwareu.hcl-software.com%2Fcourses%2Flesson%2F%3Fid%3D279): In this lesson, you see the different recorded demos with DX in action.

- [Try HCL Digital Experience Now](https://hclsoftwareu.hcl-software.com/component/axs/?view=sso_config&id=4&forward=https%3A%2F%2Fhclsoftwareu.hcl-software.com%2Fcourses%2Flesson%2F%3Fid%3D280): In this lesson, you learn how to deploy HCL DX Solution Modules on HCL SoFy and run the previous demos on your own sandbox.
