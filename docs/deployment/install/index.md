# Install

HCL Digital Experience (DX) supports various infrastructures to cater to customers using different platforms. You can install DX as a traditional application on non-containerized platforms or deploy it on containerized platforms, such as certified Kubernetes, for hybrid and development environments.

- **[Kubernetes Deployment](./container/index.md)**  
Learn about deploying HCL DX as a cloud-native platform and optimize business-critical digital experiences for your customers.
- **[Traditional Deployment](./traditional/index.md)**  
Learn about traditional deployment requirements, high availability, supported topologies, and installation patterns.
- **[Hybrid Deployment](./hybrid/index.md)**  
Learn about hybrid deployment architecture, connecting on-premises core services to cloud-based digital asset and content components using Helm.
- **[Docker Compose](docker-compose.md)**  
Learn about deploying HCL Digital Experience 9.5 for non-production use through Docker Compose scripts and associated learning materials.
