# Installing HCL DX on Linux

Installation involves preparing the operating system, installing HCL Digital Experience (DX), and completing deployment configuration.

Roadmaps provide a high-level overview of the entire deployment process. For more information, refer to [Roadmaps to deploy your system](../../../../../get_started/plan_deployment/traditional_deployment/roadmaps/index.md)

Use the [Configuration Wizard](../../../../manage/portal_admin_tools/cfg_wizard/index.md) to complete deployment configuration. For more information, refer to Configuration Wizard in the product base documentation.

- **[Configuring Linux to install HCL DX](prep_os-linux.md)**  
Prepare the operating system to ensure a successful HCL DX installation.
- **[Setting up the IBM Installation Manager on Linux](inst_iim-linux.md)**  
Use the IBM Installation Manager to install packages such as HCL DX and IBM WebSphere Application Server.
- **[Running the HCL DX installer on Linux](../linux/running_install/index.md)**  
Ensure the system is running the immediately preceding version of HCL DX with applicable fixes applied before installing.
- **[Configuring post-installation settings on Linux](inst_next_steps-linux.md)**  
Use the Configuration Wizard to set up integration with databases, LDAP directories, clusters, and additional components.
- **[Upgrading the SDK on Linux](sdk_upgrade-linux.md)**  
Change the SDK Java Technology Edition version using the applicable HCL DX Combined Fix Pack.
