title: Creating a Search component
---

A Search element defines the layout of a form that is used to display search results. To use a Search element, you must create a Search component. You cannot add Search elements to authoring templates, sites, site areas, or content items.

To create a Search component, open the applications menu and go to **Content > Web Content Management** and then click **New > Component > Search**.
