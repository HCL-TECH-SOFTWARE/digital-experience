title: Selecting users
---

You use the User Selection element to select the user names to store in the component.

1. Click **Select Users** to select the users to store in the component.
2. Use the **Search** field to search for users.
3. Select users in the **Search Results** field and then click **Add** to add them to the selected list.
4. To remove users, select them in the **Selected Names** field and then clicking **Remove Selected Names**.
